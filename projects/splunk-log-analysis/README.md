# Splunk Security Log Analysis

## Project Overview

This project focuses on learning security log analysis
and identifying suspicious authentication activities
using Splunk SIEM.

## Project Objective

- Understand security log analysis.
- Monitor authentication events.
- Identify failed login attempts.
- Investigate suspicious login activities.
- Understand basic brute-force detection techniques.

## Tools and Technologies

- Splunk SIEM
- Windows Security Event Logs
- Search Processing Language (SPL)
- Windows 10/11

## Key Security Concepts

- Authentication Monitoring
- Failed Login Detection
- Brute-Force Attack Investigation
- Security Event Analysis
- Incident Investigation

## Investigation Methodology

1. Identify the available security log sources.
2. Review authentication events.
3. Examine failed login attempts.
4. Identify suspicious patterns.
5. Investigate relevant event details.
6. Document findings and observations.

## Important Windows Event IDs

| Event ID | Description |
|---|---|
| 4624 | Successful Logon |
| 4625 | Failed Logon |
